# Rexa 제품 비전

## 1. Rexa는 무엇인가

Rexa는 웹 문서를 AI가 바로 이해하고 활용할 수 있는 형태로 재구성(Recast)해주는 로컬 퍼스트 문서 엔진이다.

개발자는 Rexa를 통해:

1. 원하는 문서 사이트를 선택하고
2. 로컬에 고품질 Markdown으로 저장한 뒤
3. MCP(Model Context Protocol)를 통해
4. AI(ChatGPT, Cursor, Windsurf 등)에게 **"신뢰 가능한 공식 문서"**를 직접 제공할 수 있다.

**Rexa는 단순한 크롤러가 아니다.**
**AI가 학습하고 추론하는 입력(Context)을 관리하는 도구다.**

## 2. 해결하려는 문제

### 🔴 문제 1: AI는 공식 문서를 "항상 정확히" 보지 못한다

- 웹 검색은 불안정하다
- 문서 버전이 다르다
- 일부 페이지는 접근하지 못한다
- SPA 기반 문서는 제대로 읽히지 않는다

→ AI가 틀린 문서를 근거로 답변하는 문제가 발생한다.

### 🔴 문제 2: 문서 기반 RAG 시스템은 설정이 너무 복잡하다

- 크롤러 설정
- HTML 파싱
- Markdown 정제
- 스토리지 구성
- 벡터 DB 연동

→ 개인 개발자나 소규모 팀은 시작조차 어렵다.

### 🔴 문제 3: "로컬에서 바로 쓰는 AI 지식 엔진"이 없다

- 대부분 SaaS 중심
- 클라우드 업로드 필수
- 보안/프라이버시 문제
- 오프라인 사용 불가

## 3. Rexa의 핵심 가치 제안 (Value Proposition)

### ✔ Local-first

- 모든 문서는 로컬에 저장
- 인터넷 없어도 AI 사용 가능
- 개인정보/회사 내부 문서도 안전

### ✔ AI-native

- MCP 기반 설계
- AI가 문서를 "탐색"할 수 있는 구조
- 단순 파일 저장이 아닌 Context Provider

### ✔ Zero-infra

- DB 없음
- 서버 없음
- Node.js만 있으면 바로 사용

### ✔ Trustable Knowledge

- 사용자가 선택한 "공식 문서"만 사용
- 출처 명확
- 답변 신뢰도 상승

## 4. 타겟 사용자

### 🎯 1차 타겟: 개인 개발자

ChatGPT / Cursor / Windsurf를 주로 사용하는 개발자
"이 프로젝트는 이 문서 기준으로만 답해줘"가 필요한 사람

### 🎯 2차 타겟: AI 기반 개발 팀

- 사내 기술 스택 문서 통합
- 내부 가이드 + 외부 공식 문서 혼합
- RAG를 쓰고 싶지만 복잡한 인프라는 원하지 않음

### 🎯 3차 타겟: SaaS / 엔터프라이즈

- 문서 자동 수집
- 팀 단위 공유
- 보안 격리
- SLA 필요

## 5. Rexa의 핵심 컨셉

### 🧩 "문서는 파일이 아니라 Context다"

Rexa는 문서를:

- HTML 페이지
- 텍스트 덩어리

가 아니라,

**AI가 참고해야 할 지식 단위(Context)**

로 취급한다.

그래서:

- 문서 목록 제공
- 문서 메타데이터 관리
- 문서 탐색 인터페이스(MCP)

를 핵심 기능으로 둔다.

## 6. 사용 시나리오 (User Story)

### 🟢 개인 개발자

"React Native 프로젝트 중인데, Expo 문서만 기준으로 답해줘."

```bash
rexa crawl https://docs.expo.dev
rexa serve --mcp
```

→ AI는 Expo 공식 문서만 참조한다.

### 🟢 팀 사용

"우리 팀은 React + 내부 가이드 기준으로만 개발한다."

- Rexa Cloud에서 문서 등록
- 자동 업데이트
- 팀 MCP 엔드포인트 공유

## 7. 제품 구조 (개념)

```
[ Docs Website ]
        ↓
      Rexa
        ↓
[ Local Markdown Knowledge Base ]
        ↓
[ MCP Server ]
        ↓
[ AI Tools ]
```

**Rexa는 AI와 문서 사이의 인터페이스다.**

## 10. 브랜드 정체성

- **이름**: Rexa
- **발음**: 렉사
- **의미**: Re(cast) + xa
- **톤**: 미래지향, 간결, 기술적
- **메시지**: "AI에게 무엇을 가르칠지는, 당신이 정한다."

## 11. Rexa가 궁극적으로 가는 방향

Rexa는 단순한 도구가 아니다.

**AI 시대의 "개인 지식 인프라"**

개발자는 자신만의 문서 기준을 만들고
AI는 그 기준 안에서만 사고한다

Rexa는 AI의 입력을 통제하는 첫 번째 도구가 되는 것을 목표로 한다.

## 12. 한 문장으로 요약

**Rexa는 웹 문서를 AI가 신뢰할 수 있는 지식으로 재구성해주는 로컬 퍼스트 문서 엔진이다.**
